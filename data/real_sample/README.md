# Real-sample data

These files describe the target middle-distillate hydrocarbon sample measured by the authors. They are not NIST data.

- `target_sample_slices.csv`: 460 processed GC-EI-MS slices after retention-index calibration, baseline subtraction and TIC normalisation.
- `target_sample_summary.csv`: sample-level reference values and model outputs.
- `target_sample_structural_composition.csv`: measured and predicted structural composition.
- `target_sample_predicted_curves.csv`: predicted boiling-point curves.
- `target_sample_fingerprint_neighbours.csv`: fingerprint distances to the 200 virtual complex mixtures.
- `target_sample_nearest_farthest_properties.csv`: nearest and farthest virtual-sample property comparisons.

The raw vendor files are not included. The processed slice table contains the normalized m/z channels needed to reproduce the real-sample route.
